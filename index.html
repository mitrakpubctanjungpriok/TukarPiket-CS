🚀 Deploy ke GitHub + Cloudflare

📁 Langkah 1: Setup GitHub

  1. Buka github.com dan login/daftar
  2. Klik tombol "+" di kanan atas → "New repository"
  3. Beri nama repository (contoh: form-tukar-piket)
  4. Pilih "Public"
  5. Centang "Add a README file"
  6. Klik "Create repository"
  7. Klik "Add file" → "Upload files"
  8. Upload file index.html ini
  9. Klik "Commit changes"

☁️ Langkah 2: Deploy ke Cloudflare Pages

  1. Buka dash.cloudflare.com dan login/daftar
  2. Di sidebar kiri, klik "Workers & Pages"
  3. Klik "Create application" → "Pages" → "Connect to Git"
  4. Hubungkan akun GitHub Anda
  5. Pilih repository form-tukar-piket
  6. Klik "Begin setup"
  7. Project name: isi nama (contoh: tukar-piket)
  8. Build settings: biarkan kosong (tidak perlu build)
  9. Klik "Save and Deploy"
  10. Tunggu proses deploy selesai
  11. Website Anda akan tersedia di: https://tukar-piket.pages.dev

✅ Selesai!

Setiap kali Anda update file di GitHub, Cloudflare akan otomatis deploy ulang website Anda.
